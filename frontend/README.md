# Click Tracking Service - Management UI

React-based management interface for the Click Tracking Service.

## Features

- Create new short URLs with destination and optional source URLs
- View all short URLs in a table with analytics
- Search short URLs by short code, destination, or source URL
- Display click count, unique users, revenue, and conversion count
- Copy short codes and full URLs to clipboard
- Real-time analytics updates

## Tech Stack

- React 18 with TypeScript
- Vite for fast development and building
- Tailwind CSS for styling
- TanStack Query (React Query) for API state management

## Development

This frontend runs in Docker as part of the complete stack.

### Start Development

```bash
# From project root
docker compose up -d --build
```

Access at: http://localhost:8080

### Making Changes

```bash
# Edit files in frontend/src/

# Rebuild frontend
docker compose up -d --build frontend

# View logs
docker compose logs -f frontend
```

### Configuration

The frontend is configured via Docker Compose environment variables:

```yaml
# docker-compose.yml
frontend:
  environment:
    API_BASE_URL: http://localhost:3000
```

Change `API_BASE_URL` in `.env` file to point to your API.

## Build

The frontend is built automatically by Docker using a multi-stage build:

1. **Build stage**: Compiles React app with Vite
2. **Production stage**: Serves static files with Nginx

## Deployment

The frontend can be deployed separately from the backend:

```bash
# Build frontend image
docker build -t my-frontend ./frontend

# Run frontend container
docker run -p 8080:80 -e API_BASE_URL=https://api.yourdomain.com my-frontend
```

Or deploy static files to:
- AWS S3 + CloudFront
- Vercel
- Netlify
- Any static hosting service

## Environment Variables

- `API_BASE_URL`: Backend API URL (set at runtime via Docker)
